## 7. RAG / knowledge architecture

The recovered HNK Agent RAG architecture defines a layered retrieval priority:

`CANONICAL > CODEX > SOURCE > HISTORY > EXPERIMENTAL`

The source types are:

- CANONICAL — operational rule.
- CODEX — consultation synthesis.
- SOURCE — integral source.
- HISTORY — historical context.
- EXPERIMENTAL — hypothesis/roadmap.

Recommended chunk metadata includes:

`id, work_id, title, domain, document_type, source_file, source_section, coverage_state, evidence_class, authority_level`

The dedup schema adds an important distinction:

**coverage state and evidence class are independent dimensions.**

A full work may have only partial indexing coverage.

The provenance graph also establishes:

`WORK` = intellectual/document identity

`SOURCE` = evidence container/location

One work may have multiple source containers without becoming duplicated.
