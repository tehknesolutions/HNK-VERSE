# DISCOVERY 004 — WORLD + CREATION MODEL LOCK

**Status:** LOCKED  
**Date:** 2026-09-22  
**Authority:** Creator-approved HNK-VERSE product canon  
**Depends on:** DISCOVERY 002 and 003

## 1. World hierarchy

`PERSONAL_VERSE → WORLD → REGION → CITY → VILLAGE → LAND → STRUCTURE → MODULE → OBJECT → MATERIAL`

The hierarchy is compositional, not merely navigational.

A higher layer is built from and influenced by lower layers while still being able to define rules for them.

## 2. World as persistent state

A world is not only a map.

A world is:

`SPACE + RULES + ENTITIES + RESOURCES + HISTORY + CULTURE + ECONOMY + ECOLOGY + KNOWLEDGE + SYMBOLIC/METAPHYSICAL CORRESPONDENCE + PROVENANCE`

Rendering is only one representation of this deeper world truth.

## 3. Creation principle

HNK-VERSE adopts the principle:

> **THE WORLD IS PLAYABLE MATTER.**

Anything represented as editable WORLD_STATE is potentially transformable through some valid combination of:

`PERMISSION + KNOWLEDGE + SKILL + RESOURCE + TOOL + PROCESS + TIME`

Exceptions include immutable platform infrastructure, security boundaries, protected canon and deliberately fixed world laws.

## 4. Creation ladder

Creation scales progressively:

1. **PLACE** — move/place an existing object.
2. **DECORATE** — customize surfaces, arrangement and appearance.
3. **ASSEMBLE** — combine components.
4. **CRAFT** — produce functional objects.
5. **BUILD** — create structures.
6. **ENGINEER** — connect systems and automation.
7. **DESIGN** — author reusable blueprints/templates.
8. **PLAN** — organize settlements and infrastructure.
9. **GOVERN** — define local policies and systems.
10. **WORLD-BUILD** — define geography, ecosystems and world rules.
11. **VERSE-BUILD** — connect worlds and higher-order rule systems.

## 5. Knowledge-driven crafting

Crafting must not reduce to arbitrary recipe memorization.

Preferred causality:

`OBSERVE → APPRAISE → LEARN PROPERTY → DISCOVER PROCESS → GATHER → PROCESS → COMBINE → CREATE → TEST → RECORD`

Knowledge may come from CODEX-HNK, HNK-Idioma, experimentation, mentors, Agents, institutions, exploration, professions, world history and discovery.

Both known recipes and discovered processes are valid.

## 6. Materials and properties

Materials are modeled by properties rather than item IDs alone.

Property families may include physical, structural, thermal, biological, energetic, technological, symbolic, linguistic, metaphysical, economic and ecological dimensions.

Not every world needs to expose every property family.

## 7. Structures as systems

Structures are not merely decorative geometry.

They may provide shelter, storage, production, research, education, commerce, social gathering, worship/ritual, transport, defense, governance, Agent residence, creature habitat and automation.

A HOME may therefore evolve into a workshop, laboratory, school, guild, market, temple, farm, factory, portal hub or another functional space.

## 8. Settlement simulation

External scale:

`HOME → LAND → VILLAGE → CITY → REGION → NATION → WORLD → WORLDS → VERSE`

Each scale unlocks a new simulation concern:

- **HOME** — life, objects and relationships.
- **LAND** — resources, production and ecology.
- **VILLAGE** — community, roles and shared facilities.
- **CITY** — services, infrastructure, economy and organization.
- **REGION** — logistics, ecology, routes and resource networks.
- **NATION** — governance, policy, culture and large-scale technology/economy.
- **WORLD** — global/planetary rules and systems.
- **WORLDS** — portals, travel, trade and divergence.
- **VERSE** — higher-order relationships and orchestration between worlds.

## 9. World laws

Each world has a versioned `WORLD_RULESET`.

Rule domains may include time scale, day/night cycle, gravity/movement, building permissions, destructibility, resource regeneration, death/respawn, conflict/PvP, magic, technology, economy, Agent autonomy, creature ecology, language constraints, climate, portals, progression and access control.

World laws may differ radically between worlds, but changes require provenance and sufficient authority.

## 10. HNK deep structure

World rules are local.

HNK meta-architecture remains deeper than local world rules.

A Creator may author a world with a different surface culture, magic system, technology model or progression while the Verse still preserves HNK Identity, Personal Verse continuity, canonical authority boundaries, Lucidity invariants, provenance and HNK deep meta-architecture.

## 11. Metaphysical correspondence

A created object or event may have simultaneous states:

`PHYSICAL_STATE`
`SYMBOLIC_STATE`
`METAPHYSICAL_CORRESPONDENCE`
`INTERPRETATION_STATE`
`EVIDENCE_STATE`

These must not collapse into each other.

A physical placement is a runtime fact. Symbolic meaning and HNK metaphysical correspondence are separately modeled. User or Agent interpretation remains interpretation. Evidence remains evidence.

## 12. Player-created worlds

A World Creator may eventually define terrain, biomes, structures, resources, creatures, Agents, institutions, technologies, magic systems, quests, economy, laws, progression, language surfaces, portals and access permissions.

Generated content does not automatically become HNK canon.

## 13. Creator tooling

The long-term creator experience supports three surfaces over the same canonical world state:

- **In-world creation** — build while playing.
- **Visual authoring** — edit terrain, structures, rules and systems.
- **Advanced authoring** — schemas, scripting, AI-assisted generation and reusable packages.

## 14. Destruction, provenance and recovery

World modification must preserve intentional destruction, rollback and provenance.

`CREATE / MODIFY / DESTROY → EVENT LOG → VERSIONED STATE → RECOVERABLE HISTORY`

Important player-authored structures require permissions and recovery mechanisms to prevent griefing or accidental irreversible loss.

## 15. ZERO creation proof

ZERO proves only:

1. one land exists;
2. one home exists;
3. one resource can be gathered;
4. the resource has at least one meaningful property;
5. one knowledge item explains or unlocks a process;
6. one creation process exists;
7. one object can be created;
8. the object can be placed in the world;
9. placement changes persistent WORLD_STATE;
10. logout/login preserves the modification;
11. telemetry preserves provenance;
12. the created object has at least one gameplay function beyond decoration.

## 16. Locked decisions

1. The world is persistent, compositional and editable state rather than a static map.
2. 2D/2.5D isometric rendering remains independent from deeper editable world truth.
3. Knowledge, skill, resources and permission are prerequisites for meaningful transformation.
4. Creation progresses from object placement to Verse creation.
5. Structures have systemic functions, not decoration only.
6. Settlement/civilization scale unlocks new simulation layers.
7. World laws are versioned and creator-configurable at sufficient authority.
8. HNK meta-architecture persists beneath divergent local worlds.
9. Physical, symbolic, metaphysical, interpretive and evidentiary states remain distinct.
10. Persistent world modification requires provenance and recoverability.
