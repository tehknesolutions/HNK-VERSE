# DISCOVERY 003 — PLAYER IDENTITY & PROGRESSION

**Status:** PROPOSAL — awaiting Creator lock  
**Depends on:** DISCOVERY 002 — Product Fantasy Lock

## 1. Design question

Who is the player inside HNK-VERSE, what is the relationship between human, identity, avatar and Personal Verse, and what does progression actually mean?

## 2. Proposed identity model

Do not collapse user, avatar and Verse into one object.

`HUMAN → HNK_IDENTITY → PERSONAL_VERSE → AVATAR(S)`

### HUMAN

The real person using the product.

### HNK_IDENTITY

Persistent account-level identity and provenance layer. Owns permissions, achievements, authoritative history and Verse links.

### PERSONAL_VERSE

The user's persistent universe and primary manifestation container.

### AVATAR

An embodied playable representation inside a specific world/context. An avatar is not automatically identical to the human, identity or entire Verse.

This allows future alternate embodiments, worlds, roles and forms without corrupting identity continuity.

## 3. Progression is capability, not only level

Traditional numerical level may exist, but core progression should be measured by expanded capability:

`I CAN PERCEIVE`
→ `I CAN UNDERSTAND`
→ `I CAN PRACTICE`
→ `I CAN MAKE`
→ `I CAN TRANSFORM`
→ `I CAN ORGANIZE`
→ `I CAN GOVERN`
→ `I CAN DEFINE RULES`
→ `I CAN CREATE WORLDS`

## 4. Proposed player-scale titles

Working titles only:

1. INDIVIDUAL
2. INHABITANT
3. APPRENTICE
4. SPECIALIST
5. ADVENTURER
6. MASTER
7. BUILDER
8. FOUNDER
9. GOVERNOR
10. WORLD CREATOR
11. VERSE CREATOR

These must not replace the Sephirotic progression. They describe manifestation scale, not spiritual rank.

## 5. Parallel progression dimensions

The player should be able to progress through several independent but connected dimensions:

- **Knowledge** — what has been learned/verified/unlocked.
- **Language** — what can be named/read/expressed in HNK-Idioma.
- **Skill** — repeated executable capability.
- **Profession** — coherent mastery cluster.
- **Relationship** — trust/history with humans, Agents and creatures.
- **Creation** — objects and structures that can be produced.
- **Territory** — scale of world that can be modified.
- **Civilization** — scale of systems that can be organized.
- **World Authority** — which rules the user may configure.
- **Manifestation** — ability to turn knowledge/intention/action into persistent world state.

## 6. Three different forms of authority

HNK-VERSE must keep these separate:

### Runtime authority
What the player is technically permitted to do.

### World authority
What the diegetic world permits the avatar/entity to do.

### Canonical authority
What may define or modify HNK canon.

Being a World Creator must never automatically grant canonical authority over HNK itself.

## 7. Agent relationship

Persistent Agents may have:

- identity;
- memory;
- goals;
- skills;
- relationships;
- homes;
- inventories;
- occupations;
- world knowledge;
- personal history;
- bounded permissions.

Agent continuity should create world history, but Agent speech or interpretation is not HNK canon by default.

## 8. Creature relationship

Creatures should not exist only as combat units.

Possible roles include:

- companions;
- ecology participants;
- exploration partners;
- resource finders;
- workers;
- transport;
- production;
- guardians;
- training/bond progression.

Creature canon and any relationship to other HNK universes remain separate decisions.

## 9. Proposed fundamental player loop

`DISCOVER → LEARN → NAME → PRACTICE → GATHER → CREATE → USE → TRANSFORM → OBSERVE → RECORD → PROGRESS`

Higher-scale loop:

`BUILD → CONNECT → ORGANIZE → GOVERN → DEFINE → CREATE WORLD`

## 10. ZERO identity proof

ZERO should prove only:

1. user identity persists;
2. one avatar exists;
3. one Personal Verse exists;
4. one land/home belongs to that Verse;
5. the avatar can learn one thing;
6. learning can unlock one capability;
7. capability can create one persistent world change;
8. one Agent remembers one meaningful interaction;
9. telemetry records provenance;
10. logout/login preserves the result.

## 11. Open lock questions

Before this Discovery becomes LOCKED, Creator authority is needed on:

1. Is one **Personal Verse** mandatory per HNK Identity, or may one identity own multiple Personal Verses?
2. Can a user have multiple playable avatars inside the same Personal Verse?
3. Is the Sephirotic path a universal progression axis for every Verse, or only for HNK-official worlds?
4. Can users create worlds with rule systems that diverge strongly from HNK defaults while remaining connected to HNK-VERSE?
5. What is the minimum permanent distinction between a persistent Agent and a conventional scripted NPC?
