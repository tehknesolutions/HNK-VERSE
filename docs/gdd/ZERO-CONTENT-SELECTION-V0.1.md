## 1. Purpose

This document converts the first GDD content questions into source-grounded ZERO candidates without inventing missing HNK canon.

Authority classes used here:

- **LOCKED SOURCE** — directly established by an approved HNK-VERSE Discovery lock.
- **SOURCE-SUPPORTED DERIVATION** — directly derived from an existing HNK project source, but not yet a published CODEX-HNK runtime canonical object.
- **FROZEN LANGUAGE ASSET** — recovered HNK language registry item with FROZEN authority.
- **CONTENT CANDIDATE** — proposed ZERO content awaiting Creator approval.
- **BLOCKED** — cannot be truthfully promoted until a missing canonical source/ID exists.

## 2. ZERO sphere

**Decision:** MALKUTH  
**Status:** LOCKED SOURCE

DISCOVERY 011 already locks ZERO to the first executable Malkuth layer.

Legacy HNK source material describes Malkuth/Assiah around physical manifestation, action, practical discipline, material consolidation, home/property and concrete embodiment.

This source basis is sufficient for gameplay derivation but does not create a current CODEX-HNK runtime ID.

**Authority:** SOURCE-SUPPORTED DERIVATION

KNOW
→ WORK

→ WORLD CHANGES

### Boundary

- source status;

- canonicalRef = null;
- bridgeStatus = PENDING_CANONICAL_ID.

When CODEX-HNK publishes an approved Malkuth canonical object, the bridge must migrate to that exact versioned ID instead of preserving the provisional content as independent canon.

**Form:** VALI  
**Registry ID:** LEX-013  
**Meaning:** trabalho / trabalhar — work  
**Authority:** FROZEN  
**Certainty:** RECOVERED  
**Source authority:** @hnk/linguas

### ZERO binding status

**ZERO use:** CONTENT BINDING CANDIDATE  
**L07/Malkuth curriculum binding:** NOT CLAIMED

SimpleWay HNK currently reports L07/Malkuth with zero recovered/governed language assets. ZERO must not pretend that VALI is a recovered L07 lexeme.

Instead, the proposed game binding is transversal:

VALI
→ player encounters the form in a work/creation context
→ Persona recognizes/learns the recovered meaning
→ the UI can reveal the concept WORK
→ the relevant practical action becomes semantically understandable

This does not create grammar productivity or a new Malkuth curriculum binding.

### Why VALI

VALI is preferred over authored CANDIDATE forms because:

- it is FROZEN;
- its meaning is recovered;
- "work / trabalhar" fits the Malkuth source emphasis on action and practical manifestation;
- it can affect gameplay without requiring invented grammar.

### Current-HNK naming boundary

HNK and HENUVOKODAN remain distinct project terms.

Legacy labels in older repositories must not be used to silently collapse them into synonyms.

## 8. First persistent Agent

### Technical identity

**Stable technical ID candidate:** AGENT-ZERO-CARTOGRAPHER-001  
**Role:** Cartographer / Witness / Investigation Companion / Builder  
**Authority:** CONTENT CANDIDATE

### Display-name candidate

**METATRON**

A Project conversation source already uses the call:

"Metatron, mostre o mapa."

and frames the role as:

- witness;
- mirror;
- cartographer;
- critic;
- investigation companion;
- builder;

with explicit boundaries against being treated as priest, infallible oracle, substitute for Jesus or authority above the Creator.

### ZERO function

The first Agent should:

1. welcome/orient the player at Home;
2. know that one resource/object exists;
3. initially hold only limited knowledge;
4. teach or point toward the first investigation without omniscience;
5. remember whether the player discovered VALI / the practical principle;
6. observe the Wooden Box after placement;
7. react to the persistent change;
8. accept or refuse one small gift/resource transfer;
9. retain the relationship event after reload.

### Agent epistemic design

The Agent must be able to say something that is:

- memory;
- belief;
- testimony;

without it becoming WORLD TRUTH automatically.

### Metatron boundary

If the display name METATRON is promoted, HNK-VERSE must treat it as the name/identity of a software/world Agent.

It does not by itself assert that the Agent is the theological/angelic Metatron, has a soul, or represents a verified supernatural entity.

### Promotion state

**Technical role:** READY AS ZERO CANDIDATE  
**Display name METATRON:** AWAITING CREATOR LOCK

If the name is not promoted, the exact same Agent contract can ship under another display identity without changing its stable system role.

## 10. First 10-minute content loop

1. Avatar arrives at Home in Malkuth.
2. Cartographer Agent orients the player.
3. Player notices one work-related HNK form: VALI.
4. Persona gains/recognizes the FROZEN lexeme meaning "work / trabalhar".
5. Player discovers the provisional Malkuth practical-manifestation knowledge.
6. Player finds/gathers Wood.
7. Player performs the Basic Practical Work action.
8. Event Ledger records the attempt/result.
9. Skill receives evidence.
10. Wooden Box is created.
11. Player previews and places it at Home.
12. World State persists the Box.
13. Agent observes/reacts to the change.
14. Player gives/transfers one remaining Wood unit or another small owned unit to the Agent.
15. Ownership and relationship history update.
16. Chronicle records discovery + creation + relationship.
17. Player exits.
18. Player returns.
19. Box, Skill, VALI knowledge, ownership, Agent memory and Chronicle remain.
