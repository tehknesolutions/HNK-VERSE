# HV-01.4 — MHCM ↔ World Integration Gate

Status: IN PROGRESS

## Authority boundary

- MHCM transforms typed IR and does not own World state.
- World owns Identity, Session, Presence and contextual transitions.
- MHCM output crosses into World as `PROPOSAL_ONLY` data.
- Chronicle remains the owner of persisted historical facts; this gate does not write Chronicle.

## Proven invariants

1. A valid MHCM path operation returns transformed IR while retaining the exact Presence snapshot.
2. Proposal authority carries the existing Identity, Session and Presence IDs without replacement.
3. Invalid MHCM operations throw before a World transition can be produced.
