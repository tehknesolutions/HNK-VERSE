# HV-01.4 — MHCM baseline debt discovered by integration

The World/MHCM integration gate exposed defects already present in the newly merged MHCM surface.

Observed blockers:

- runtime barrel loading reached `kode-compile.ts` with invalid module ownership imports;
- `typecheck:world` traverses MHCM and reports existing semantic-registry / KODE type inconsistencies;
- `test:mhcm` currently fails independently of the new World proposal contract with invalid TypeScript syntax in an existing script fixture.

These failures must not be hidden by weakening the World gate. HV-01.4 remains open until the MHCM baseline is repaired or isolated behind a stable public runtime surface.
